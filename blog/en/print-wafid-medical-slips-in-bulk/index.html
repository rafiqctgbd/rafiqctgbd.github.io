Download and Print Wafid Medical Slips in Bulk: A Simple Workflow for Agencies

A hundred candidates, a hundred passport numbers: looking each one up, saving the PDF, renaming it and printing it takes an office half a day. The whole job can come down to one list and one button.

By SixSeasons Labs · Updated October 2026 · 5 min read

বাংলায় পড়ুন →

Before working in a GCC country, candidates need a medical-examination appointment slip, which is looked up on Wafid (wafid.com) by passport number and nationality. For one person it's a two-minute job. For a recruiting agency with fifty or a hundred files on the desk, it's the same job a hundred times.

Where the time goes when you do it by hand

  • Looking up one at a time. Type the passport number, pick the nationality, search, and again for the next candidate.
  • Saving and naming files. A downloads folder full of near-identical PDFs, and no easy way to tell whose is whose.
  • Tracking who has no slip yet. The candidates whose slip didn't come up end up on a handwritten list.
  • Printing. Opening every PDF and printing it separately.

What a good workflow needs

Give it the whole list at once, save every slip named by passport number, skip slips already downloaded, list the candidates with no slip separately, and print everything at the end, retrying by itself if the connection drops.

Wafid GCC Slip, Download & Print: a free Windows tool

Paste a list of passport numbers or load it from a .txt file (with names next to them if you like), choose the nationality and the printer, and press one button. The tool looks up each passport's slip on wafid.com, saves it as a PDF and sends it to the printer, using SumatraPDF or, if that isn't available, Windows' own printing. Slips already in the folder are skipped, failures are retried, and passports with no slip are written to a separate file. It works through the Microsoft Edge or Google Chrome already on your PC, so there's nothing else to install: it's a single .exe.

Download for Windows

Step by step

1. Make the list

One passport number per line, with the candidate's name beside it if you want. Copying straight from Excel works; header lines and duplicate numbers are dropped automatically.

2. Choose the nationality and folder

Pick the nationality just as on Wafid's search page, and choose the folder the slips should go into.

3. Download and print

One button starts it. Each slip shows in the log as it arrives, and at the end there's a summary: how many came down, how many were already there, and how many weren't found.

4. Follow up on the missing ones

Passports with no slip, or that couldn't be downloaded, are listed in _not_downloaded.txt. Run it again later and only those are tried; the ones already downloaded are skipped.

Using it responsibly

  • Only for your own candidates. Download slips only for the people your agency is handling.
  • These are personal records. Keep passport lists and medical slips somewhere secure, and delete copies you no longer need.
  • Don't hammer the site. The tool pauses between passports; don't try to shrink that pause to run faster.
  • It's independent. The tool isn't affiliated with Wafid or GAMCA, and if Wafid changes its pages, the tool may need an update.

Good to know

  • It needs Windows 10 or 11, plus Microsoft Edge (which comes with Windows) or Google Chrome.
  • The app is digitally signed, but with a self-issued certificate, so Windows SmartScreen may warn you the first time. If you downloaded a zip, right-click it › Properties › tick Unblock before extracting; otherwise choose "More info", then "Run anyway".

The short version

A hundred slips don't need a hundred identical searches. Give it the list, press once, and get the slips, the list of missing ones and the printouts together, for your own candidates, with their records looked after.

Frequently asked questions

What happens if a passport has no slip?

It is marked separately in the log, and the number is written to _not_downloaded.txt so you can follow it up later.

If it stops halfway, does it download everything again?

No. When you run it again, slips already in the folder are skipped and only the rest are looked up.

Which printers does it work with?

Any printer installed in Windows. The tool prints with SumatraPDF, or with Windows' own printing if SumatraPDF isn't available.

Is this an official Wafid tool?

No. It is an independent, free tool, not affiliated with Wafid or GAMCA. It uses Wafid's public slip search page, just as you would by hand.
