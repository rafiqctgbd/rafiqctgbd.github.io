📋 About

NextCue is designed for people who want reliable, private reminders for the everyday things they currently track with sticky notes, memory, or nothing at all. All data lives on your device by default — no accounts required, no data collection, no ads.

It is a deliberate companion to Medicine & Health Reminder, built on the same production-hardened alarm engine, generalized beyond medicine to every other kind of recurring life event. NextCue isn't a to-do app or a project manager — there are no subtasks, projects, or collaboration features, and that's intentional. It does one thing: make sure you never forget a bill, a renewal, or a date that matters.

✨ Features

  • 68 ready-made templates across 7 buckets — Bills, Personal Events, Home & Lifestyle, Subscriptions, Renewals, Maintenance, and Health
  • Today view grouping reminders as Today / Tomorrow / This Week / Later
  • Expiry-based smart renewal reminders with automatic lead-time alerts (6 months, 3 months, 1 month, 1 week before)
  • Recurrence options — one-time, daily, weekly, monthly, and yearly
  • Full-screen alarm alerts with Done and Snooze actions
  • Swipe-to-done and swipe-to-snooze with Undo
  • Automatic snooze for unattended alarms, and missed-marking after repeated no-response
  • Reminders automatically restore after device reboot
  • History tab logging every done, snoozed, and missed action, with one-tap Restore
  • Reminder Reliability panel with live status checks and one-tap fixes
  • Four alarm tones, adjustable snooze duration, and a fully silent mode
  • Sort by time, name, or next occurrence; browse by category
  • Live search across all reminders
  • Pause all reminders temporarily with one tap
  • Share your full reminder list via WhatsApp, SMS, or email
  • Optional Google Drive backup and restore, with optional automatic weekly backup
  • Secure local data storage — no server required

🔐 Data Privacy

User privacy is a core principle of this application.

  • Data stored locally on the user's own device by default
  • No account required to use the app
  • No personal data stored on developer-owned servers
  • Google Drive backup is completely optional and off until you sign in
  • User data is never sold or shared with third parties
  • No advertisements — no advertising SDKs used
  • No analytics or tracking libraries of any kind
  • No camera, location, contacts, or SMS permissions requested

☁️ Google Drive Backup

The application optionally supports Google Drive backup and restore using the Google Drive scope:

drive.file

This lets you back up your reminders and history to your own Google Drive, so they survive a phone change, loss, or theft — and restore them on a new device in seconds.

The backup is written to a visible folder named "NextCue Backups" in your own Drive, so you can find, download, or delete the file yourself at any time. The app cannot access any other files, photos, videos, or documents in your Google Drive — the drive.file scope restricts it to only the file it created itself.

Backup options inside the app:

  • Back up now — a manual, one-time upload
  • Automatic weekly backup — optional silent background backup
  • Backup reminder — optional weekly or monthly nudge if you prefer backing up manually; uploads nothing on its own
  • Restore — replaces device data with your saved backup
  • Delete backup from Drive — permanently removes the backup file

⚙️ Technical Overview

  • Platform: Android (Kotlin), minimum Android 5.0 (API 21), targets Android 16 (API 36)
  • Storage: SharedPreferences + JSON — no database, no server
  • Alarm engine: exact alarm scheduling, ported from Medicine & Health Reminder
  • Package: com.rafiqctgbd.nextcue
  • Backup: Google Sign-In with Drive REST API v3, drive.file scope
  • Brand colour: cyan #00C4B4, deliberately distinct from Medicine & Health Reminder's blue
