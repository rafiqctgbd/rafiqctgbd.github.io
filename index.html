Free Tools

Wafid GCC Slip — Download & Print

Paste or load a list of passport numbers and this tool fetches each one's medical appointment slip from wafid.com automatically, then prints them straight away — SumatraPDF as the primary print engine, with a built-in Windows printing fallback. Built for agencies processing slips in bulk: retry logic, skip-already-downloaded, passports with no slip flagged separately, and an optional hidden (headless) browser mode for unattended runs.

Cloudburst — Bulk Cloud Folder Downloader

Pulls entire cloud folder trees — hundreds of sub-folders and files at once — down to your PC in one go. An in-app "Connect a Cloud" wizard talks to Google Drive, Dropbox, OneDrive, Box, pCloud, MEGA, Amazon S3 and 60+ other services (built on the open-source rclone project), so there's nothing to configure by hand. Browse the remote folder tree and pick exactly what to grab, queue multiple downloads with pause/resume/cancel and automatic retry, watch real percent/speed/ETA progress, and save common downloads as named one-click presets. New in v1.1.0: a dedicated BD Mouza Map tab for browsing and downloading government Mouza (land) map records straight from e-porcha.com — pick a বিভাগ > জেলা > উপজেলা > খতিয়ানের ধরন > মৌজা and grab exactly what you need, any time.
